# Pre-Coding Checklist

## Produto

- Nome do produto confirmado: `Check-In Board`
- Confirmar idioma inicial da interface
- Confirmar posicionamento curto do app
- Confirmar definição de sucesso do MVP
- Confirmar quem participa do beta inicial

## Escopo

- Confirmar funcionalidades do MVP
- Confirmar funcionalidades fora do MVP
- Confirmar papéis e permissões da versão 1
- Confirmar se tarefas entram no MVP já na primeira release
- Confirmar canais iniciais suportados por iCal

## UX E Operação

- Definir fluxo de onboarding do Host Admin
- Definir fluxo de convite para equipe
- Definir fluxo de visualização do Co-host
- Definir estados operacionais de reserva
- Definir estados das tarefas
- Definir filtros principais da lista operacional

## Dados

- Definir entidades principais
- Definir chaves únicas e estratégia de deduplicação de reservas
- Definir timezone por apartamento
- Definir política de soft delete
- Definir retenção de logs de sincronização

## Backend

- Definir stack final do backend
- Definir serviço de autenticação
- Definir estratégia de autorização por apartamento
- Definir frequência de sincronização iCal
- Definir estratégia de retries e tratamento de erro
- Definir ambiente de deploy do worker e da API

## Mobile

- Definir stack final do app
- Definir navegação inicial
- Definir gerenciamento de estado e cache
- Definir estratégia de push notifications
- Definir biblioteca de componentes inicial

## Operação Técnica

- Definir ambientes local, staging e produção
- Definir monitoramento de erro
- Definir analytics de uso
- Definir convenções de repositório e branches
- Definir seeds e dados de teste

## Validação

- Definir roteiro do beta com a usuária inicial
- Definir métricas de validação
- Definir rotina de coleta de feedback
- Definir critério para avançar para integrações mais completas
